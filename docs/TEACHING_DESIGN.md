# 教学设计：安培力方向关系学生探究

## 1. 教学定位

本工具用于高中物理安培力方向关系的课堂探究。学生手动输入电流方向、磁场方向角和安培力方向角，程序把输入重建为空间向量并绘制。它的核心价值是让学生在旋转视角和 Z-Y 正视图之间往返，比较多组现象，形成对左手定则的空间理解。

本工具不是测量仪器，也不是自动答题系统。它不采集 DIS、摄像头或教师端数据。

## 2. 建议学习目标

1. 能说明导体棒、电流、磁场和安培力所处的坐标方向。
2. 能根据角度输入判断 B、F 在 y-z 平面中的方向。
3. 能在不同视角下识别同一空间向量。
4. 能归纳安培力与电流、磁场的方向关系。
5. 能区分“输入事实”“程序重建”和“物理规律判断”。

## 3. 建议课堂流程

### 课前准备

- 教师确认网页可访问，学生设备支持 WebGL。
- 统一坐标系、角度定义和传统电流方向。
- 准备来自实验、教师端截图或预设情境的若干组 I、α、β。

### 探究阶段

1. 学生输入一组 I、α、β，点击绘图。
2. 先使用 Z-Y 正视图核对 +y、+z 及角度。
3. 切换可旋转视角，观察导体棒 x 轴与 B、F 所在平面。
4. 记录 B、F 是否垂直，以及 I、B、F 的相对方向。
5. 更换至少四组数据，比较不变量与变化量。
6. 小组用语言、手势或向量叉乘表达规律。

### 归纳阶段

- 教师引导学生把左手定则与 `F = I L × B` 对照。
- 强调程序只是按输入绘图；规律是否成立需要学生用实验和物理推理判断。

## 4. 学习证据

建议保留以下材料：

- 学生输入记录表；
- 关键视角截图；
- 小组归纳文本；
- 对错误输入的解释；
- 课前、课后同构题结果。

这些材料属于课堂研究证据，不由当前网页自动收集。

## 5. 评价建议

| 维度 | 可观察表现 |
| --- | --- |
| 坐标理解 | 能正确指出 ±x、±y、±z |
| 角度解释 | 能把 0°、90°、180°、270°映射到方向 |
| 空间转换 | 能在正视图和旋转视图中识别同一向量 |
| 规律归纳 | 能说明 I、B、F 的相互垂直与方向关系 |
| 证据意识 | 能区分实验观测、人工输入和程序建模 |

## 6. 当前边界

- 不判断学生输入的 F 是否满足左手定则。
- 不由 I、B 自动计算唯一正确的 F。
- 不保存班级、姓名或学习记录。
- 不替代真实实验和教师评价。
