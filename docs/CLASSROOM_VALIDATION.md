# 课堂验证方案

## 1. 验证目的

验证分为三层：技术正确性、课堂可用性和学习效果。代码存在不等于课堂效果已经得到证明。

## 2. 技术验证用例

对 B 和 F 分别测试：

| 输入角 | 预期物理方向 | Z-Y 正视图 |
| ---: | --- | --- |
| 0° | +y | 向右 |
| 90° | +z | 向上 |
| 180° | -y | 向左 |
| 270° | -z | 向下 |
| 360° | +y | 与 0° 同向 |

另需测试：

- I 在 +x、-x 间切换；
- 角度显示/隐藏；
- Z-Y 正视图与旋转视图；
- Pad 横屏、手机竖屏和桌面浏览器；
- 刷新后无摄像头或屏幕捕获权限请求。

## 3. 课堂可用性指标

建议记录：

- 首次完成绘图所需时间；
- 学生误解坐标或角度定义的次数；
- 触摸旋转、缩放成功率；
- 教师介入次数；
- 页面加载失败或 WebGL 失败次数。

## 4. 学习效果证据

可采用前测/后测同构题、学生解释文本、操作录像编码和访谈。建议把“能操作网页”与“理解方向规律”分开评价。
