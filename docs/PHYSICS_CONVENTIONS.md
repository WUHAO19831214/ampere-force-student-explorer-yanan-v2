# 物理约定与计算边界

## 1. 笛卡尔坐标系

物理模型采用右手笛卡尔坐标系：

- 导体棒沿 x 轴；
- +y 与 +z 构成垂直于导体棒的平面；
- `x × y = z`，`y × z = x`，`z × x = y`。

Z-Y 正视图约定为：+y 向右、+z 向上。Three.js 内部场景坐标是渲染实现，不应与物理坐标混用；`physicsToScene` 负责两者映射。

## 2. 电流方向

学生选择传统电流方向：

- `I: +x` 对应物理向量 `(1, 0, 0)`；
- `I: -x` 对应物理向量 `(-1, 0, 0)`。

这里使用约定电流方向，不是电子定向移动方向。

## 3. 磁场角 α

磁场 B 位于 y-z 平面，物理向量为：

```ts
B = (0, cos(alpha), sin(alpha))
```

因此：

| α | B 方向 |
| ---: | --- |
| 0° | +y |
| 90° | +z |
| 180° | -y |
| 270° | -z |

在 Z-Y 正视图中，也可把 α 理解为从 +y 朝 +z 方向逆时针转到 B 的角；等价地，是从 B 顺时针转回 +y 的角。

## 4. 安培力方向角 β

F安培力同样位于 y-z 平面，物理向量为：

```ts
F = (0, cos(beta), sin(beta))
```

β 的四个基准方向与 α 相同。当前学生端直接按 β 重建 F，而不是由 I、B 自动推导 F。

## 5. 左手定则与向量叉乘

对直导线，方向关系可写为：

```text
F = I L × B
```

其中 `I L` 的方向取传统电流方向。左手定则是这一叉乘方向关系的课堂表征：磁感线穿入掌心，四指指向电流，大拇指指向安培力。

需要区分两件事：

- 物理规律给出 I、B、F 应满足的关系；
- 当前程序只把学生输入的 I、α、β 可视化。

## 6. 输入、计算与判断

| 内容 | 来源 |
| --- | --- |
| I 为 +x 或 -x | 学生输入 |
| α、β | 学生输入，范围 0° 到 360° |
| I、B、F 的三维方向向量 | 程序按上述公式计算 |
| 角弧、标签、视角 | 程序绘制 |
| F 是否满足 `I L × B` | 当前程序不自动判断 |
| 学生答案是否正确 | 当前程序不评分，由学生与教师论证 |

## 7. 研究记录注意事项

论文或报告中应写“学生输入方向数据，程序重建并可视化向量”，不应写成“程序自动测得磁场和安培力方向”或“程序自动验证左手定则”。
