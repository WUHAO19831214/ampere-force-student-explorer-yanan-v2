# 与教师端应用的关系

## 1. 两端分工

| 维度 | 学生端 | 教师端 |
| --- | --- | --- |
| 数据来源 | 学生手动输入 I、α、β | 屏幕捕获 OCR、摄像头视觉及教师操作 |
| 主要任务 | 空间观察、比较、归纳 | 采集、校准、展示、保存课堂证据 |
| 权限 | 无摄像头、无屏幕捕获 | 需要用户授权屏幕和摄像头 |
| 部署 | 独立静态网页 | 课堂教师计算机运行的综合网页 |
| 自动判断 | 不判断学生答案 | 可计算角度与垂直关系，但不替代教师评价 |

## 2. 共享概念模型

两端共享以下教学约定：

- 导体棒沿 x 轴；
- B、F 位于 y-z 平面；
- 使用传统电流方向；
- 通过 Z-Y 正视图和三维旋转理解方向；
- 区分实测数据、视觉识别和程序建模。

## 3. 运行关系

学生端与教师端是两个独立仓库和独立部署：

- 学生端不导入教师端源码；
- 学生端运行时不连接教师端；
- 当前没有账号、数据库、实时同步或课堂房间协议；
- 教师可以把教师端观测到的一组 I、α、β 口头或书面提供给学生，再由学生手动输入。

## 4. 证据链建议

研究中可把两端材料串联为：

1. 教师端保存实验画面、OCR 数值、视觉方向和三维快照；
2. 学生端记录学生输入与观察结果；
3. 学生说明两者是否一致及理由；
4. 教师用原始实验证据和物理规律进行复核。

必须保留来源标签，避免把学生输入误写为传感器实测，也避免把程序绘图误写为真实实验图像。
